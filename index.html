ぽろっと　ことばの練習

絵カードを使って、ことばの練習をするアプリです。ひとりでも、ご家族などといっしょでも使えます。言語聴覚士が、ことばの練習にかかわってきた経験をもとに、使いやすさを考えて設計しました。

  • 名詞1,060語。すべてに絵と読み上げ音声がついています
  • 4つの練習。聞く・読む・話す・始めの音
  • インターネット通信を行いません。電波のない場所でも、すべての練習ができます
  • 無料です。広告の表示、アカウントの登録はありません
App Store でダウンロード

2026年8月現在、iPhone・iPad でお使いいただけます。

4つの練習

聞く(きく) 読み上げられたことばに合う絵を選びます。
読む(よむ) 表示された文字に合う絵を選びます。
話す(はなす) 絵を見てことばを話し、できたかどうかを [◯] [？] で記録します。アプリが声を聞き取って判定することはありません。
始めの音(はじめのおと) 絵に合うことばの、始めの音を選びます。

名詞1,060語。すべてに絵と読み上げ音声

収録した1,060語すべてに、絵と読み上げ音声があります。音声は低めの声・ゆっくりめの話し方に調整しました。

文字は漢字とふりがなの併記が標準です。漢字だけ・かなだけにも切り替えられます。

絵や音声などはAIで作成しました。収録した語や絵は、すべて言語聴覚士が確認して選んでいます。

難しさを選べます

難しさは、次の3つから選びます。

  • ことばのレベル … 易しい / 普通 / 難しい
  • 枚数 … 2枚 / 4枚 / 6枚
  • まぎらわしさ … 弱い / 普通 / 強い

最初は「易しい・2枚・弱い」です。後からいつでも変えられます。アプリが自動で変えることはありません。

条件に合うことばが少ないときは、選んだ枚数より少ない枚数で出ることがあります。

「食べる」「からだ」「家の中」など、場面ごとに出すことばの範囲を選ぶこともできます。

練習の記録

名前を登録して練習すると、練習の種類ごとに、ことばのポイントがたまります。10ポイント以上になったことばには ◎ が付きます。記録の画面では、練習したことばの数、合計ポイント、ポイントの移り変わりのグラフを見られます。ポイントで、練習に出すことばを絞ることもできます。

お名前の登録は任意です。複数の方の記録を分けて残すことも、名前を登録せずに練習することもできます。

練習の種類ごとに、取り組んだことばの数に合わせて庭(にわ)の絵が変わります。同じことばは、何回練習しても1つと数えます。庭の絵が変わるかどうかに、正解・不正解は関係しません。

完全オフライン。広告なし

このアプリはインターネット通信を行いません。絵と音声はアプリに入っているため、電波のない場所でもすべての練習ができます。

登録したお名前と練習の記録は、すべてお使いの端末の中にだけ保存され、外部に送信されることはありません。アカウント登録、広告表示、アクセス解析はありません。
